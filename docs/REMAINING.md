# EME — বাকি কাজ

আসল সাইট `web/`। রিপোর রুট থেকে চালান:

```powershell
python -m http.server 8770
```

তারপর `http://localhost:8770/web/`। রুটের `index.html` এই ঠিকানায় পাঠিয়ে দেয়। নতুন ফিচার শুধু `web/`-এ।

লাইভ সাইট: `https://eme3.netlify.app`। পাবলিশ ডিরেক্টরি `web`।

## হাতে করতে হবে

এই SQL ফাইলগুলো রিপোতে আছে। Supabase SQL এডিটরে পুরো ফাইল পেস্ট করে Run না করলে নিচের কাজগুলো চালু হয় না।

1. `supabase/f7_payments.sql` — ডেলিভার হলে COD `paid`, পুরো ক্যানসেল হলে pending পেমেন্ট `failed`, কাস্টমার রিফান্ড আবেদন, অ্যাডমিন রিফান্ড।
2. `supabase/f8_live_guest_chat.sql` — লগইন ছাড়া লাইভ চ্যাট পড়া। মেসেজ পাঠাতে এখনো লগইন লাগে।
3. `supabase/f9_reel_engagement.sql` — রিল ভিউ ও শেয়ার একবার প্রতি ব্রাউজার সেশনে। না চালালে সেই দুই সংখ্যা বাড়ে না। সেভ, লাইক, কমেন্ট আগের টেবিল দিয়েই চলে।
4. `supabase/f10_signup_roles.sql` — একবার Run। এরপর রেজিস্টারে Customer, Vendor, Admin বাছাই করা যায়। পুরনো অ্যাকাউন্ট কাস্টমার, ভেন্ডর বা অ্যাডমিন পেজ থেকে রোল বদলায়। না চালালে “Use this account as …” বাটন সেই কথাই দেখায়। ভেন্ডর বাছলে দোকান সাথে সাথে approved হয়।

`supabase/f6_orders.sql` আগে চালানো থাকলে আবার চালানোর দরকার নেই।

5. লাইভ ক্যামেরা অনেক দর্শকের জন্য। LiveKit ক্লাউড অ্যাকাউন্ট লাগবে:

```powershell
supabase functions deploy livekit-token
supabase secrets set LIVEKIT_URL=wss://YOUR.livekit.cloud LIVEKIT_API_KEY=... LIVEKIT_API_SECRET=...
```

সিক্রেট না থাকলেও হোস্টের ক্যামেরা নিজের রুমে খোলে। আলাদা নেটওয়ার্কের দর্শকের জন্য সিক্রেট লাগে। রুম, চ্যাট, পিন করা পণ্য সিক্রেট ছাড়াও থাকে।

6. Supabase → Authentication → URL configuration। Site URL আর Redirect URLs:

- `http://localhost:8770`
- `https://eme3.netlify.app`

নাহলে পাসওয়ার্ড রিসেট আর ইমেইল কনফার্ম সাইটে ফিরে আসে না। রিসেট লিংক প্রোফাইল পেজে খোলে।

7. Netlify Site configuration → Access থেকে সাইট public করতে হবে। নাহলে ভিজিটর “Sign in to Netlify” দেখে।

8. বেশি ডেমো পণ্য ও আসন্ন লাইভ চাইলে `supabase/seed_more_storefront.sql` একবার Run। এটাও এখনো চালানো হয়নি।

## এখনো বানানো হয়নি

পেমেন্ট:

- bKash / Nagad চার্জ হয় না। চেকআউটে শুধু ক্যাশ অন ডেলিভারি
- কুপন কলাম নেই
- ইমেইল বা এসএমএস নোটিফিকেশন নেই
- রিফান্ডে স্টক ফেরে না
- চেকআউটের ডেলিভারি এখনো ঢাকা ৬০ / বাইরে ১২০ (`place_order`)। অ্যাডমিন Settings-এর `default_shipping_fee` চেকআউট বদলায় না

## যা হয়ে গেছে

- হোম, ক্যাটাগরি, প্রোডাক্ট, সার্চ, দোকান, লগইন, প্রোফাইল, ঠিকানা, উইশলিস্ট
- টিল হেডার, সাদা সার্চ, ক্যাটাগরি আইকন সারি, প্রোডাক্ট কার্ডে ছাড় ও দাম
- হোমের ডিল কার্ড ক্যাটালগের আসল পণ্য দিয়ে। পাশে নতুন পণ্য ও অনুমোদিত দোকানের কার্ড। সমতল স্টুডিও ছবি আর ঘরের বা কাঠের মেঝের ছবি দুটোই কার্ডের ওপর কাটা হয়। ঘরের ছবিতে প্রথমবার একটা ব্রাউজার মডেল নামে, ততক্ষণ গোল ফ্রেম থাকে
- রিল ফিড, লাইক, কমেন্ট প্যানেল (নিচে), রিপ্লাই, সেভ, সেভ করা রিলের পাতা। লগইন থাকলে কমেন্ট সেভ হয়। কাউন্টার আপডেট ফেল করলেও কমেন্ট থাকে (`f11_comment_insert.sql` লাইভ ডাটাবেসে চালানো আছে)। লগইন না থাকলে Post লগইন পেজে নিয়ে যায়, তারপর এই রিলে ফেরে
- শেয়ার নিচের প্যানেলে রিলের লিংক দেখায়। Copy link চাপলে কপি হয়। ফোনে সিস্টেম শেয়ার শিটের বাটনও থাকে
- অনুমোদিত দোকান রিল পোস্ট করতে পারে। লিংক রিলসের উপরে এবং অ্যাকাউন্ট মেনুতে। উইন্ডোজে ভিডিওর টাইপ খালি থাকলেও MP4, WebM, MOV আপলোড হয়। দোকান না থাকলে Sell পেজে যায়
- কার্ট, চেকআউট (COD, `place_order`), কাস্টমার অর্ডার, pending ক্যানসেল, ইনভয়েস প্রিন্ট
- ভেন্ডর স্টুডিও: প্রোডাক্ট, ছবি, দোকান খোলা, লাইভ শিডিউল, পেআউট পড়া, চ্যাট। হেডারে “দোকান খুলুন” / “নতুন পণ্য”
- ভেন্ডর অর্ডার স্ট্যাটাস `pending` → `processing` → `shipped` → `delivered`
- প্রোডাক্ট রিভিউ (ডেলিভার হওয়া অর্ডারের পর)
- লাইভ রুম প্লেয়ার (`livekit-token`) ও সাইন-ইন দর্শক গোনা। হোমে চলমান ও আসন্ন লাইভ
- অ্যাডমিন: দোকান, মডারেশন, অর্ডার ও রিফান্ড, রোল, ক্যাটাগরি, সেটিংস, ডিসপিউট, পেআউট
- দোকান ফলো, Following, প্রোডাক্ট/দোকান থেকে মেসেজ, Help, পাসওয়ার্ড রিসেট ইমেইল
- কাস্টমার হোম `pages/customer.html`, ভেন্ডর স্টুডিও `pages/vendor.html`, অ্যাডমিন `pages/admin.html`
- রেজিস্টারে Customer / Vendor। অ্যাডমিন নিজে থেকে নেওয়া যায় না (`f12_catalog_and_roles.sql` লাইভ ডাটাবেসে চালানো আছে)
- হোমের “জিজ্ঞেস” ক্যাটালগের নাম, দাম ও দোকান থেকে উত্তর দেয়। না মিললে শিরোনামের embedding থেকে কাছের পণ্য আনে। ক্যাটালগে না থাকলে উত্তর বানায় না
- পণ্য দেখা, কার্টে রাখা, কেনা, আর সার্চ `user_events`-এ লেখা হয়। হোমে “আপনার জন্য” সেই দেখা পণ্য দেখায়
- `products`, `reels`, `live_streams`-এর `embedding` শিরোনাম থেকে ভরা হয় এবং cosine HNSW ইনডেক্স আছে
- শপারের হেডার, ফুটার, হোম, রেজিস্টার, কমেন্ট ও ক্যাটালগ চ্যাট BN/EN বদলায়। পণ্যের নাম যেমন সেভ আছে তেমন থাকে
- `web/README.md` চেকআউটকে `place_order` বলে, লাইভকে LiveKit প্লেয়ার বলে
- `docs/DATABASE.md`-এ `sales_count` `place_order` লেখে
- ফ্রন্টএন্ড চেক: `node --test web/js/catalogTerms.test.mjs`
